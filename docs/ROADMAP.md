# Public Roadmap

This roadmap is public and may change based on community feedback, maintainer capacity, security needs, and technical feasibility.

## How roadmap decisions are made

We use several inputs:
- GitHub Discussions polls
- Feature requests and survey submissions
- Bug severity and maintenance cost
- Security and platform priorities
- Maintainer availability

A high-voted item is important, but it may still be delayed if it is risky, expensive, or blocked by other work.

## Status legend

- Planned: accepted and likely to be worked on
- In Progress: currently being developed
- Under Review: being evaluated or designed
- Future: valuable, but not scheduled yet
- Done: shipped
